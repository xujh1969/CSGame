# TASK-010 | 街道环境细节与战场远景

状态：待开始。2026-10-30 用户追加环境需求。本卡仅登记计划，须 TASK-009 完成定义及人工验收通过后才可实施，不表示已放行或已完成。

## 目标与范围

在既有城市巷战视觉方向上加强街道真实感和远景层次，保留可读的敌人轮廓、主路线和真实掩体碰撞。

- 地面：增加不规则碎石、破碎砖块、纸片、废弃杂物、污渍与材质变化，避免等距、均匀铺撒；装饰分布使用可复现 seed，不堵主路线。
- 水洼：在路面低洼处成簇布置不规则积水，表现潮湿过渡、反光和边缘污泥；避免整条街变成镜面或反射过亮影响交战识别。
- 棕榈树：补充街道及中远景植被轮廓，以疏密变化和高低错落组织视线；所需树干、树冠、叶片资源先审计，缺少时列入用户建模交付清单，不把占位宣称为成品。
- 电线：楼间、街道上方和电杆间布置交错且有自然垂度的电线，连接可解释的固定点，体现“横七竖八”的街区层次；不穿入可玩高度或遮住瞄准中心。
- 天际线：用高低、尺度、屋顶轮廓各异的建筑填满远处地平线，避免裸露空白缝隙、整齐重复与建筑突然消失。
- 空气透视：远景逐层降低对比度与饱和度，结合雾气、悬浮灰尘呈现模糊、灰蒙的战场纵深；保持中近景敌人和掩体清晰，沿用用户“克制景深、优先看清敌人”的要求。
