# TASK-002 | 第一人称枪械与命中/换弹

## Goal
建立独立 WeaponController + 第一人称武器灰盒 ViewModel，左键射击、右键 ADS、R 换弹并显示简单临时弹量文字。

## Scope
配置弹仓与库存、射速/冷却、开镜、射线命中、目标受击组件、掩体阻挡；自动测试 `test_reload_math` 与最近碰撞行为。
## Out of Scope
真实武器模型、复杂动画、物理弹丸。
## Acceptance
- [ ] 射击不会在墙后敌人身上凭空产生命中。
- [ ] 30/90 -> 发 10 枪 -> 20/90 -> reload -> 30/80。
- [ ] 无弹、无库存、重复 R、换弹中射击与重开行为有明确结果。
- [ ] 模块化接口供 Enemy 及 HUD 使用。
