# TASK-000 | 项目盘点 + 骨架 + 灰盒可启动场景

## 目标
创建或维护现有 Godot 项目，使其能打开、运行一个最小灰盒街道，并留下可靠的验证记录。**这是唯一允许首次直接执行的任务。**

## 工作范围
1. 检查 `project.godot`、Git 状态、现有 scenes/assets/scripts、Godot 的实际版本。已有工程必须保留。
2. 项目不存在时初始化 Godot 4.x 项目；存在时只补充必要结构。设置主场景、InputMap、窗口、基本渲染档。
3. 做一段 20m 灰盒地面、两侧简单建筑和路障，放一个 Player/Camera3D 占位；可用临时自由观察镜头确认场景加载，但不要在本任务实现完整角色运动。
4. 按 ARCHITECTURE 建立最低限度目录、一个简单导入/启动测试和运行记录。
5. 完成 `docs/09_DECISIONS_RISKS.md` 的实际版本/路径/渲染器项。

## 不做
复杂射击、敌人、人物建模、真实贴图、程序生成整条街。

## 验收
- [ ] `project.godot` 可被本机引擎加载（非零退出不能忽略）。
- [ ] Godot GUI 能展示 20m 灰盒街道（有截图或注明环境无 GUI 不能验证）。
- [ ] 地面和障碍有简单静态碰撞体；标明暂未验证运动。
- [ ] InputMap 存在且清楚定义动作映射。
- [ ] 已产出文件清单、验证命令、实际输出摘要、尚未验证项目。

## 输出格式
修改内容 / 验证证据 / 手工确认步骤 / 风险缺口 / 是否放行 TASK-001。
