# TASK-005 | 完整战斗循环、HUD 与基础特效

## Goal
实现生命/弹量/准星 HUD、射击与命中特效占位、基本 3D 音效、关卡胜负和重开，形成可完成的 80m 单关。
## Scope
HUD 单向订阅玩家/武器状态；枪口火花/弹着点灰尘、简易烟雾、临时音效；失败胜利界面及暂停流程。
## Out of Scope
商业级音效资产、爆炸物理破坏、完整菜单与存档。
## Acceptance
- [ ] 80m 关卡从启动、战斗、换弹、受伤到胜利完整闭环。
- [ ] 玩家死亡与胜利条件不会互相触发错乱。
- [ ] UI 信息与真实弹量/生命值保持一致。
- [ ] 低画质档可以减少或禁用非关键烟尘。
