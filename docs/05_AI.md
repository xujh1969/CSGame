# 05 敌人 AI 设计与公平性

## TASK-004 实现（2026-10-28）

- 三名敌人预先实例化在 SpawnMarkers 上，EncounterManager 仅激活一次，不在触发时生成。休眠敌人也可受伤/失能；提前失能不会再次激活或补刷。
- EnemyBase 的状态、感知、射击、表现拆为独立脚本，复用通用 HealthComponent。参数通过导出属性配置；默认反应 0.65s + 瞄准 0.45s、3 发点射、发间隔 0.18s、冷却 1.5s；单发伤害 8，固定 seed 的约 2° 散布。敌人初始 HP 100。
- E01 沿实际静态碰撞离线烘焙的 CornerNavigation.tres，使用 NavigationAgent3D + CharacterBody3D 在街角和指定掩体间短距离往返。路径点阈值 0.2m，容纳导航栅格约 0.1m 的竖直偏差；没有传送或绕过碰撞。
- E02 固定 4.2m 高窗平台，不带 NavigationAgent；E03 固定站/蹲。站立 1.8m、蹲伏 1.0m，胶囊与可见体同步改变；警戒变黄，失能变灰并压低为倒地占位，碰撞关闭。
- 感知使用 110° 水平视野，距离 25m / 窗口 35m；LOS 和攻击都查询 WorldStatic | Cover | PlayerBody（mask 7）且排除自身。每发重新检查 LOS，并检查眼睛→枪口→瞄点的真实遮挡。
- 看不见玩家时仅保留最后已知位置。SEARCH 2s 超时后退回指定掩体、冷却并重新观察，采用这个固定站位循环，避免一次触发后永久休眠卡住关卡。
- 玩家 HP=0 后停止输入/持续射击并取消换弹；敌人也停止攻击。只使用临时 HP 文字与现有 Reset test，正式 GameFlow 留给 TASK-005。
- 验证命令、导航问题修复证据、GUI 画面和未验证项见 `logs/TASK-004.md`。

## MVP 类型
- E01 CornerAmbusher：玩家进入 T1 区后从街角边缘进入射击姿态。必须在墙后预埋，不能凭空出现。
- E02 WindowSentry：固定二层窗口（例高约 4m），有限角度观察、射击、短暂停火。MVP 不要给它移动式寻路任务。
- E03 CoverRifleman：在 1.0–1.2m 矮墙后站/蹲切换，开火短点射、停止、再次暴露。MVP 不需复杂搜索所有掩体。

## 状态机
`DORMANT` -> `ALERT` -> `AIM` -> `FIRE_BURST` -> `SEEK_COVER` / `COOLDOWN` -> `AIM`；生命 <= 0 -> `DEAD`。脱战可回到 `SEARCH`（有超时）但不得永远卡死关卡。

| 状态 | 输入 | 必需行为 | 退出 |
|---|---|---|---|
| DORMANT | 关卡触发未发生 | 不射击，可处于掩体/房间内 | Trigger 激活 |
| ALERT | 触发/目击玩家 | 转向目标，有警示动作/音效，至少 0.4s 反应窗 | AIM |
| AIM | LOS 有效、玩家进入范围 | 对准并停顿，检查遮挡 | FIRE_BURST 或 SEARCH |
| FIRE_BURST | 可视且射击冷却好 | 有限 2–5 发的游戏化点射，尊重掩体遮挡 | COOLDOWN |
| SEEK_COVER | 需要回避 | 使用指定 CoverMarker，失败就留在安全位置 | AIM / SEARCH |
| SEARCH | 丢失 LOS | 面向最后已知位置，若干秒后回指定掩体重新警戒 | AIM / SEEK_COVER |
| DEAD | HP <= 0 | 停止所有攻击，关闭有效攻击碰撞 | 终止 |

## 可控参数（初始建议）
- 感知距离 25m；视野角 110°；初次反应 0.4–0.9s；每次爆发间隔 1.0–2.0s；敌人的枪械精度根据难度调节（不要逐帧精确命中）。
- 窗口警戒兵感知距离较长，可到 35m，但必须受窗口几何与 LOS 限制。
- 最多同时激活 3 名敌人（80m demo），500m 第一关再扩展 4–6 名。
- 避免“敌人感知穿墙”和“玩家绕到楼后仍准确被锁定”。玩家遮挡目标若断 LOS，应以最后已知位置处理而不是持续跟踪。

## 技术协议
- `EnemyBase` 统一实现 `activate()`, `apply_damage()`, `get_state()`, `is_alive()`。
- `Perception` 使用 PhysicsRayQueryParameters3D，明确 exclude 自身、固定碰撞层 mask；检查最近碰撞对象是否玩家。
- 局部平面移动的敌人才启用 NavigationAgent3D，且导航区域必须实际烘焙、路径可达性有测试。窗口兵是固定炮位。
- SpawnMarker 含 id、archetype、facing、trigger_id、cover_marker_id；若资源缺失，用不同颜色/形状灰盒敌人。
- 玩家不在视觉可观察位置生成新敌人；允许 AI 初始休眠，触发后再运动、但不允许突兀瞬移。

## 自动化用例
1. 玩家在墙后时敌人不造成命中（同样利用真实物理几何）。
2. 玩家露脸，敌人在警示/反应时间后才攻击。
3. 多次进入 Trigger 不重复生成/计数。
4. 敌人死亡后不再攻击，死亡事件只触发一次。
5. 关卡重开后 AI 状态、弹量和触发器全部初始化。
