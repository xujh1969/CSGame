# 04 玩家控制、武器、掩体数值规范

> 本页数值为**初始游戏参数**，通过 Resource/配置文件暴露并经过手感测试微调；不是现实枪械参数。

## 玩家控制
| 功能 | 建议起始值 | 验收方式 |
|---|---|---|
| 走路 | 4.0m/s | 平地移动无抖动 |
| 跑步 | 6.5m/s | Shift 临时加速，放开恢复 |
| 蹲走 | 2.0m/s | Ctrl 保持，镜头和碰撞盒平滑降低 |
| 跳跃 | 约 1.0m 的起跳高度 | 可跳过低门槛，不能跳穿棚顶 |
| 站立摄像头 | 高度 1.7m | 不穿模 |
| 蹲下摄像头 | 高度 1.1m | 有头顶障碍时不能站起穿物 |
| 鼠标灵敏度 | 可调默认 0.0025rad / 相对位移单位 | 视角稳定，无输入累加加速 |
| FOV | 75° 垂直（暂定） | ADS 改变 FOV 时不改变真实命中方向 |

`Crouch`: 双向过渡及防头顶穿模校验。`Sprint`: 跑时不能 ADS；是否允许边跑边射应作为开关（MVP 默认禁止 ADS，腰射可选）。

## 一支虚构步枪原型
- `mag_size=30`、`reserve_rounds=90`、`fire_interval=0.11s`、`reload_duration=2.2s`、`damage=25`（单人普通敌人 HP=100，便于初期调试）。
- 左键持续射击时按射速扣弹；空仓不能开火；R 在有储备弹时换弹，弹匣未空也可换弹；计算 `need = mag_size - current` 并从 reserve 转入。
- 换弹过程不能凭重复按 R 多次补子弹；换弹结束瞬间统一转移弹量；死亡或切关时取消待完成异步动作。
- 射击使用 Camera RayCast / `direct_space_state.intersect_ray` 命中世界最近对象；武器枪口是视觉位置，远距命中由摄像机瞄点主导，必要时做枪口→目标遮挡二次验证，以免贴墙时枪穿墙射击。
- 启动最小随机扩散/后坐力，后续才优化镜头回弹与枪口特效。
- 为 HUD 发出单向 `ammo_changed`；不让 HUD 自行推断弹量。

## 生命与游戏流程
- 玩家 `max_health=100`，敌人 `max_health=100`；先用统一简化伤害。
- 每次命中只处理一次；死亡后 AI 停止、命中盒关闭、触发一次 `actor_died`。
- 场景中没有友军和无关居民，因此不涉及阵营混战识别逻辑。
- 玩家死亡：进入失败 UI，停止战斗输入，允许重开。胜利需所有必需遭遇处理并越过终点 Trigger。

## 掩体
- MVP **不做自动吸附掩体系统**，以手动 Ctrl 蹲下 + 真实碰撞遮挡为主，更直观、更不易造成摄像机卡墙。
- 若玩家在 1.0–1.2m 高的矮墙后蹲下，应被大部分直线射击遮挡；站立时能射过墙缘（依据真实几何判定）。
- 所有掩体的视觉尺寸和碰撞一致到合理程度；特效粉尘/烟不意味着子弹真实穿透或破坏了掩体。

## 动画优先级
死亡/失能 > 换弹 > 射击/ADS > 移动 > Idle。对于 FPS 视角，先完成枪的基础摆动与换弹占位；角色全身动画放在外部 GLB 到位后替换。
