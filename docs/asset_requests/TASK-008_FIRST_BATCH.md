## 图生3D描述（可配合上述图片使用）

单个废弃民用五门两厢车，尺寸长4.2米、宽1.8米、高1.5米。浅米白色旧漆，局部褐色锈蚀与掉漆，引擎盖和左前翼子板轻度凹陷，车窗缺失或暗色，简化但完整的车内结构，四个完整可辨认的车轮。车身仍保留真实汽车结构和清楚的车门、轮拱、保险杠，不要融化成废铁团。完整三维物体，无背景、无地面底座、无人、无武器、无火焰烟雾，无品牌标志和文字。尽量把车身与车轮分成独立部件，材质保留细节，适合游戏实时渲染。

## 如需重新生成参考图片

主体同上；前左三分之四视图、长焦或弱透视，整车完整入画，四边留约10%空白，浅灰纯色工作室背景、柔和均匀光照、所有部位清晰，无景深、无强投影、无水印、无尺寸线。参考图应展示单个车辆，不要生成战斗场景或多物件拼图。

本次实际英文生成提示词的关键约束为 single abandoned compact five-door civilian hatchback、front-left three-quarter view、4.2m × 1.8m × 1.5m、dusty faded cream paint、localized rust、recognizable tires、neutral gray studio background、no brands/text/people/fire/smoke。使用内置imagegen，非CLI/API路径。
