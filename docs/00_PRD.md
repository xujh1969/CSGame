# 00 产品需求文档（PRD）· Urban Corridor FPS

## 2026-10-29 已授权的后续扩展

用户提供写实场景/敌人参考并要求多关卡，随后要求按设计继续开发。TASK-007 仅新增两关短灰盒以验证跨关、当前关重试与最终关完成，原80m保持独立回归；参考图对应的正式三关、美术、角色和最小进度保存仍分后续任务。下面单关 MVP 范围保留为历史基础合同，不将本轮骨架称为正式战役完成。

## 1. 游戏定位
- 类型：离线单人、第一人称、线性关卡、城市街道战斗；不做 PVP、不做真实战争事件映射。
- 核心体验：玩家沿街推进 → 观察风险 → 与突然但公平出现的敌人交战 → 利用掩体与换弹窗口生存 → 到达关卡目标。
- 视觉：现实质感的破损城市，不以血腥细节为卖点。烟、尘、火、建筑破损和声音提升氛围。
- 平台：Windows 键鼠优先；目标设备参考 RTX 2060，初版使用灰盒资产。

## 2. 先交付 80m 纵切片（MVP），后扩展 300–500m 第一关
| 范围 | 纵切片必备 | 后续扩展 |
|---|---|---|
| 玩家 | WASD、鼠标视角、跑/跳/蹲 | 侧身探头、滑铲可考虑 |
| 武器 | 一支虚构步枪；射击、ADS、换弹、弹量、后坐 | 多武器、换枪 |
| AI | 街角/矮墙/窗口 3 敌人，受伤与失能 | 转移掩体、协同行为 |
| 掩体 | 混凝土墙、路障、木箱可阻挡子弹 | 特定轻质物体破坏 |
| 视觉 | 简易枪口光、火花、灰尘、烟雾 | 精细粒子、动态光照 |
| HUD | 准星、血量、子弹、目标和失败/胜利 | 战术信息与小地图 |
| 场景 | 80m 可玩灰盒街道，左右视觉变化 | 5 风格区段、约 300–500m |

## 3. 主玩法循环
发现视线风险（环境/敌人声画信号）→ 寻找掩体与观察角度 → 短促交战和补弹 → 清除威胁 → 解锁安全前进段 → 下一个空间变化。敌人有最短反应时间，使玩家有公平应对机会。

## 4. 标准键位
WASD 移动；鼠标观察；Shift 跑；Space 跳；Ctrl 蹲（按住，V2 可切换）；左键射击；右键 ADS；R 换弹；Esc 暂停/释放鼠标。全部配置为 InputMap。

## 5. 80 米纵切片完整通过条件
- 启动后可进入街道且在主线内移动 80m；不穿地板、墙、箱子；不卡死。
- 遇见 3 名敌人（街角、窗口、矮墙）；至少一次正面对敌、一处高处威胁、一处掩体对抗。
- 被挡住时玩家射击不会穿透实心混凝土；敌人射击同样遵守遮挡。
- 完整射击 1 弹匣、换弹、消耗储备弹量；HUD 同步正确；血量归零可失败重开。
- 处理完既定遭遇后到达终点触发胜利；重新开始后的结果可重复。
- 不要求这阶段具有生成图级别的精细美术、不要求完整人物骨骼动画。

## 6. 明确不做（避免 Codex 无边界扩张）
多人网络、开放世界、可驾驶车辆、可摧毁所有建筑、复杂布娃娃物理、大规模随机城市、存档系统、内购、复杂剧情、完整自动换皮、复杂室内关卡。需求变化通过 Decision Log 审核。

## 7. 非功能性要求
- 每个功能有可复现测试，渲染效果可通过画质档位关闭或降低。
- 所有数值可配置；不把游戏玩法绑定到特定 3D 模型。
- 适配 16:9，初期 1280x720 与 1920x1080 检查 UI 和可见性。
