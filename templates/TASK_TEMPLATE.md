# TASK-NNN 简短任务标题

## Goal
一个可在游戏里看见或操作的目标。
## Input Context
必须阅读的 docs；现有文件与实现状态。
## Scope
列出最多 3–5 项必做事项。
## Exclusions
明确本任务不做什么。
## Files/Interfaces
预计新增/修改文件（Codex 需先核查现有工程）。
## Acceptance
- [ ] 场景能加载且无运行错误
- [ ] 指定交互/行为实际可重现
- [ ] 对应自动/手动测试通过
- [ ] 更新 README/日志与未验证事项
## Verify
提供要在本机执行的真实命令、操作步骤和预期结果。
## Stop Conditions
资源缺失、任务冲突、测试失败时应报告而非跳关。
